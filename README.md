# SALES DATA ANALYSIS PROJECT

## Project Overview
This project analyzes sales data using Microsoft Excel. It helps understand sales performance, profit, customer purchasing behavior and product performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- VLOOKUP
- INDEX-MATCH
- IF and Nested IF
- Charts
- Conditional Formatting
- Slicers and Timeline

## Project Tasks
1. Dataset Selection and Import
2. Data Cleaning and Preparation
3. Pivot Tables and Data Analysis
4. Advanced Excel Formulas
5. Data Visualization
6. Interactive Dashboard
7. Documentation

## Key Findings
- East region generated the highest sales.
- Electronics generated the highest profit.
- Pen Pack was the best-selling product by quantity.
- June recorded the highest monthly sales.

## Conclusion
This project demonstrates practical Excel skills for data cleaning, analysis, visualization and interactive reporting.
